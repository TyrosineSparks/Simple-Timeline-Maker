# 时间线 Timeline · 历史时间线设计器

一个参考简单的时间线设计工具，纯静态 Web 应用，双击 `index.html` 即可在浏览器打开使用。

## 快速开始

- **网页**：https://tyrosinesparks.github.io/Simple-Timeline-Maker/
- **本地直接打开**：双击 `index.html`（或拖入浏览器）。
- **本地服务（可选，图片跨域等场景推荐）**：
  
  ```bash
  # 任选其一
  python -m http.server 8080
  # 或
  npx serve .
  ```
  然后访问 `http://localhost:8080/`。

首次打开会自动载入一份「世界历史时间线」示例；点工具栏「示例」可随时恢复。

## 功能对照（参考 time.graphics）

| 功能 | 说明 |
| --- | --- |
| 事件（点） | 单个时间点，标题 / 日期 / 描述 / 链接 / 图片 / 类别 |
| 时段（范围） | 起止日期，画布上为横条，可拖动两端调整范围 |
| 纪元（Era） | 背景色带 + 顶部名称，表达大历史分期 |
| 类别（Category） | 颜色分组，事件/时段按类别着色，支持过滤 |
| 时间尺度 | 自适应刻度：小时 / 天 / 周 / 月 / 年（1/2/5 规整步长） |
| 公元前 / 公元后 | 支持 `300 BCE`、`300 BC`、`公元前300`、`-300` 等写法 |
| 缩放平移 | 滚轮缩放（以鼠标为中心）、拖拽空白平移、双击适配、缩放百分比 |
| 轴线 | 拖动改变时间轴线高度 |
| 拖拽改期 | 拖动事件圆点改日期；拖动时段两端改起止；拖动时段中部整体平移 |
| 图片 | 事件可挂 URL 或本地文件，画布上显示缩略图 |
| 撤销 / 重做 | 按钮或 Ctrl+Z / Ctrl+Shift+Z |
| 导出 | PNG 图片、JSON 项目文件（可保存/打开）、打印（可另存 PDF） |
| 自动保存 | 编辑实时存入浏览器 localStorage，刷新不丢失 |

## 日期写法

- `1945`、`1945-08`、`1945-08-06`、`1945年8月6日`
- `300 BCE` / `300 BC` / `公元前300` / `前300年` / `-300`（均为公元前）
- `AD 476` / `公元476`
- `今天` / `now` / `present`
- `1960s`（年代）、`约 1500` / `c. 1500`（模糊前缀）

## 操作提示

- **选中**：点击画布元素或左侧列表项。
- **拖动**：事件圆点 / 时段（两端=调整范围，中部=整体移动）。
- **快捷键**：`Delete` 删除选中、`Esc` 取消选中、`Ctrl+S` 保存项目文件。

## 目录结构

```
index.html        入口 + 界面结构
css/style.css     样式
js/dateutil.js    日期解析 / 格式化 / 刻度
js/model.js       数据模型 + 撤销重做
js/sample.js      示例数据
js/render.js      Canvas 渲染 + 命中区域
js/interaction.js 指针交互（拖拽 / 缩放 / 平移）
js/ui.js          工具栏 / 列表 / 表单 / 类别
js/export.js      PNG / JSON / 打印
js/main.js        启动 / 自动保存 / 快捷键
```

数据保存在浏览器 `localStorage`（键 `timeline-project`）；用「保存 / 打开」按钮可把项目导出为 `.json` 文件备份或迁移。
